A transparent way to ask a practical question: when many sustainability projects look good, which ones still deserve attention after value and implementation difficulty are considered together?

What SVDF does — in six steps

1. ReadChecks whether your data match the paper schema or the general portfolio schema.
2. NormalizePlaces unlike measures on comparable percentile scales.
3. Build shared valueCombines economic, environmental and stakeholder reach with a geometric mean.
4. Build complexityCombines implementation burden, scale and volatility. Lower is better.
5. Find the frontierRemoves any option beaten by another option on both lower complexity and higher shared value.
6. InterpretShows the surviving choices. Management still considers budget, ethics, feasibility and local priorities.

What the result means

Run an analysis to receive a plain-language interpretation.

The model

SVGj = (Ej × Vj × Sj)1/3

E = economic value, V = environmental value, and S = stakeholder reach. The geometric mean is intentionally non-compensatory. If one value dimension is zero, another dimension cannot completely hide that absence.

ICj = 0.40Bj + 0.35Lj + 0.25Rj

B = implementation burden, L = scale, and R = volatility or uncertainty proxy. A project is dominated when another project has lower-or-equal IC and higher-or-equal SVG, with at least one strict improvement.

What is new here?

SVDF does not force every sustainability project into one winner-takes-all ranking. It reframes shared-value selection as a non-dominated frontier problem. CSV gives the strategic meaning of value. The frontier logic is adapted from Discovery Plane Theory. Experience Architecture is used after screening as a light organisational question: can evidence actually change the set of actions the institution can take?

The practical distinction is simple: a project can look valuable, yet still be dominated. A project can survive the frontier, yet still fail in practice if the organisation cannot act on the evidence.

How to read the output

SVG near 1 means the alternative is relatively strong across the three declared value dimensions. IC near 0 means it is relatively easier under the declared complexity components. Frontier = true means no other observed alternative is unambiguously better on both dimensions. These are relative screening measures, not rupees, tonnes of CO₂, causal effects, or a promise that a project should be funded.

Two accepted input formats

General portfolio: project_id, project_name, economic_value, environmental_value, stakeholder_reach, implementation_burden, scale, volatility.

Paper reproduction: the bundled UNICON-derived event table uses the published proxy fields documented in the README.

Limits and responsible use

SVDF is a decision-support tool. Results depend on the alternatives, measures and weights supplied. It does not replace financial due diligence, engineering assessment, stakeholder consultation, ethics review, or managerial judgement. The paper event estimates are adjusted associations and are not randomized causal effects.
