Shared Value Decision Frontier

One-click strategic screening for sustainability portfolios. Lower implementation complexity and higher shared value gain are preferred.

The browser version never stores data. For private APIs use the local Python app with the SVDF_API_KEY environment variable.

Model

SVG is the geometric mean of economic, environmental and stakeholder-reach scores. IC combines intervention burden, building scale and baseline volatility. A project survives if no alternative has both lower-or-equal IC and higher-or-equal SVG.

SVDF research software. Paper dataset derived from UNICON (Moraliyage et al., 2022).
